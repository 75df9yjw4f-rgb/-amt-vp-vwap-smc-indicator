# Конфигурация DCA-бота для Veles

Это параметры для ручного ввода в конструкторе. Ключи биржи и токен Veles здесь не нужны
и нигде в репозитории не хранятся.

## Проверенная конфигурация

| Поле в конструкторе | Значение |
|---|---|
| Направление | Long |
| Стартовый ордер | 1 единица базового размера |
| Количество страховочных ордеров | 7 |
| Шаг страховочных ордеров | 1.5% |
| Коэффициент шага | 1.2 |
| Коэффициент объёма (мартингейл) | 1.4 |
| Тейк-профит | 1.5% от средней цены входа |
| Стоп-лосс | выключен (см. замер ниже) |
| Плечо | 1 (без плеча) |
| Перезапуск цикла | сразу после закрытия |

**Что из этого следует арифметически, до всякого теста:**

* полная сетка требует **34.4 единицы** капитала при стартовом ордере 1 — то есть если стартовый
  ордер $30, на инструмент нужно держать **больше $1 000** свободными, иначе последние
  страховочные ордера не исполнятся;
* последний страховочный ордер стоит на **−19.4%** от цены входа. Всё, что глубже, сетка
  не покрывает: позиция остаётся полностью набранной и продолжает терять.

Эти два числа стоит посчитать для любой конфигурации **до** запуска, потому что именно они,
а не тейк-профит, определяют, что произойдёт в плохом сценарии.

## Создание через API

У Veles есть API (`veles.finance/api/`), закрытый токеном. Скрипт `create_bot.py` рядом с этим
файлом создаёт бота по конфигурации выше. Токен он читает из переменной окружения
`VELES_TOKEN` — он не передаётся мне, не пишется в файл и не попадает в историю команд,
если задать его как `read -s`.
