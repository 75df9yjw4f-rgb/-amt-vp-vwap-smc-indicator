## ⚠️ О проверке компиляции — честно

**Офлайн-компилятора Pine Script не существует.** Единственный компилятор — серверный, внутри Pine Editor на TradingView. В этой среде его нет, поэтому **я не могу подтвердить критерий «компилируется без ошибок» собственной проверкой.**

Что сделано вместо этого:
1. Код написан по актуальной спецификации Pine v6 (документация проверена в этой же сессии).
2. Проведён статический аудит на типичные причины ошибок компиляции — найдено и исправлено 8 штук (список ниже).
3. Проверены баланс скобок, отсутствие табов, корректность отступов-продолжений, порядок объявлений (ни одна функция не вызывается раньше объявления).

**Ваш шаг:** вставить `src/ACE.pine` в Pine Editor и нажать «Add to chart». Если компилятор выдаст ошибку — пришлите текст, поправлю в течение одной итерации.

### Исправлено на этапе самопроверки
| # | Проблема | Почему это ошибка |
|---|---|---|
| 1 | `const string` объявлены **до** `indicator()` | Declaration statement обязан быть первым оператором скрипта |
| 2 | `active / float(enabled)` | В Pine нет каста `float()`; и деление `int/int` — **целочисленное**, coverage всегда давал бы 0 или 1. Заменено на `* 1.0` |
| 3 | `math.pow(0.5, age / float(halfLife))` | То же самое: затухание работало бы ступенями |
| 4 | `switch` без ветки по умолчанию | Защита от невыводимого типа результата |
| 5 | `switch ... => na` в `deltaProxy` | Неоднозначный тип `na` в ветке. Переписано на `if/else if` |
| 6 | `dbgRow(...), r += 1` через запятую | Запятая для цепочки *операторов* в Pine не гарантирована — разнесено по строкам |
| 7 | Debug-таблица на 16 строк при 21 строке вывода | Выход за границу таблицы → runtime error. Увеличено до 24 |
| 8 | `plot(na, ...)` | Тип серии невыводим |

## Обнаруженные ограничения (новые, сверх задокументированных)

1. **`request.footprint()` блокирует скрипт на тарифах ниже Premium.** Не «возвращает na» — именно блокирует. Это решает стратегию публикации, а не только код. См. `08-footprint.md §5` — требуется ваше решение (вариант A/B/C).
2. **Один footprint-запрос на скрипт.** `ticks_per_row` — глобальный параметр; нельзя одновременно взять footprint текущего ТФ и старшего.
3. **Footprint-дельта — не bid/ask.** Классификация по направлению цены подбара. Исходный вывод «настоящей дельты нет» остаётся верным.
4. **Footprint = source drift.** Введена третья категория честности наряду с repaint и lag.
5. **Целочисленное деление Pine** — системный риск для всей scoring-математики. Зафиксировано правилом: любое деление счётчиков пишется через `* 1.0`.
6. **Офлайн-компиляции Pine не существует** — критерий A1 подтверждается только вами.
