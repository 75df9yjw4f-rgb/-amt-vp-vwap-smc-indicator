# 28 — Полная очистка состояния

Проведена по прямому запросу. Эксперимент 1 (гипотеза H1 «сжатие → вниз», урок
L2, 493 сделки на 7 сегментах) закрыт и убран из рабочего состояния.

## Удалено

| Что | Объём |
|---|---|
| Леджеры сделок (6 шт. + 1 отбракованный) | 26.7 МБ, 493 живые сделки |
| `beliefs.json`, `beliefs_final.json` | 6 убеждений B1–B6 со статусами и историей |
| Все каталоги политик (`policies`, `policies_seg2/4/5/7/8`) | 8 версий политик, правила R0/R00/R1 |
| `baseline/BASELINE-v3.json` | эталон сравнения вместе с его результатами |
| Состояние эксперимента «пустой график» | `state.json`, `slots.json`, `classified.json` |
| Нарезка сегментов (`TEST/SEG4/SEG5/SEG6/SEG7/SEG8.csv`) | чтобы новый эксперимент резал данные сам |
| Списки сегментов внутри `screen.py`, `loso.py`, `robust.py` | обнулены |

`run.py` теперь отказывается стартовать без явно указанных баров и каталога
политик — пустое состояние не может быть перепутано с рабочим.

История сохранена в git под тегом **`archive/experiment-1-xauusd-h1`**.
Это не обход очистки: рабочее состояние пусто, система ничего оттуда не читает.

## Оставлено

**Код цикла:** `features.py`, `policy.py`, `ledger.py`, `engine.py`,
`beliefs.py`, `behavior_diff.py`, `report.py`, `review.py`, `run.py`,
`verify_change.py`, `regime.py`, `screen.py`, `loso.py`, `robust.py`,
`analyze_seg.py`.

**Защиты:** `tests/test_barrier.py` (барьер + негативный контроль),
`tests/test_kill.py` (механизм убийства гипотезы). Барьерный тест **переписан
как самодостаточный**: раньше он читал данные прошлого эксперимента и после
очистки падал. Защита, которая молчит именно при старте нового эксперимента, —
не защита. Теперь строит свои бары и свою политику.

**Сырые данные:** `research/data/XAUUSD-15m-raw.csv` — это бары, а не результаты.

**Скиллы:** `.claude/skills/` (6 скиллов Claude Trading Skills) не тронуты.

**Документы 13–27** оставлены как методологическая история и **помечены
необязывающими**: ни одна цифра оттуда не входит в решения нового эксперимента.

## Чего очистка НЕ делает

Она стирает файлы, но **не стирает то, что я уже видел**. На тех же барах
XAUUSD я знаю помесячный результат, знаю, что вышло 58% и +27.4R, знаю, какие
месяцы были плохими. Прогон на этих же данных после очистки не будет новым
экспериментом — он будет прогоном с чистыми файлами и грязным наблюдателем.

Единственное, что делает эксперимент действительно новым, — **бары, которых я
не видел**.
