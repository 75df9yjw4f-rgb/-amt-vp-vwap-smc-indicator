## 1. ЧЕГО В ДАТАСЕТЕ НЕТ И КАК ЭТО ЗАКРЫТО

Экспорт ACE **не содержит ни FVG, ни BOS/CHoCH** — эти величины ACE считает, но не
плотит (док. 14, §1.4). Поэтому оба восстанавливаются в харнессе, и оба —
**по дословному определению из исходника ACE**, а не «по смыслу».

### 1.1 FVG — точное зеркало `src/ACE.pine` строки 741–757

```
bullish: low[t] > high[t-2]        зона [high[t-2], low[t]]
bearish: high[t] < low[t-2]        зона [high[t], low[t-2]]
минимальный размер: size >= ATR(14)[t] * 0.15      (minFvgAtr, дефолт ACE)
```
Подтверждается на закрытии **третьего** бара `t`. Значит торговать её можно **не раньше
бара t+1**.

### 1.2 Слом структуры — зеркало строк 887–899, режим `closeBreak` (дефолт ACE)

```
пробой вверх на баре t:  close[t] > SH,  где SH — последний подтверждённый
                         свинг-хай, ещё не пробитый
пробой вниз:             close[t] < SL
оба на одном баре:       направление решает close >= open   (правило ACE)
structDir = направление последнего пробоя
```
Свинги берутся из экспортированных маркеров: пивот на баре `t−5`, цена `high[t−5]` /
`low[t−5]`. Проверено на данных: 1226 из 1226 совпадений при swingLen = 5.

### 1.3 Чем это может отличаться от ACE

ACE ведёт собственный учёт активных зон, их митигации и «ожидающих» уровней структуры.
Харнесс ведёт свой, более простой. Совпадение определений FVG и условия пробоя —
дословное; совпадение всей машины состояний — **не гарантируется и не заявляется**.

## 2. ПРАВИЛА ВХОДА — ЗАФИКСИРОВАНЫ

**LONG** (все условия одновременно, проверка на закрытии бара `u`):

1. `BIAS[u] >= порог` (варианты A и B ниже)
2. `structDir == +1` — последний слом структуры был вверх
3. Существует активная **bullish** FVG, сформированная на баре `t < u`
4. `low[u] <= fvg_top` — цена вошла в зону
5. `close[u] > open[u]` — реакция вверх
6. `close[u] > fvg_bot` — бар не закрылся сквозь зону
7. Это **первый** сигнал по данной FVG; после срабатывания зона снимается с учёта

**SHORT** — зеркально: `BIAS <= −порог`, `structDir == −1`, bearish FVG,
`high[u] >= fvg_bot`, `close[u] < open[u]`, `close[u] < fvg_top`.

**Вход** по `close[u]`. Дополнительных фильтров нет.

### 2.1 Срок жизни FVG — зафиксирован заранее

Зона активна **не более 100 баров** после формирования, затем снимается. Слово «свежая»
в гипотезе требует ограничения; 100 баров (5 часов на 3m) выбраны до прогона и
**подбираться не будут**.

### 2.2 Два теста порога BIAS

| | Порог |
|---|---|
| **A** | 0.15 (нейтральный порог ACE) |
| **B** | 0.35 (порог «weak» в ACE) |

## 3. ВЫХОД — ОСНОВНОЙ ВАРИАНТ

`TP = 0.15%` и `SL = 0.15%` от цены входа — те же, что в основном варианте Phase 0,
ради сопоставимости. Максимум удержания 48 баров. Одна позиция за раз.

Бар, содержащий и TP, и SL, засчитывается как **SL** (пессимистично, как в Phase 0).
Число таких баров сообщается отдельно как `ambiguous`.

Структурный стоп (за границей FVG) — **отдельный эксперимент**, в основной результат
не подмешивается.

---

## 4. ЗАЩИТА ОТ ЗАГЛЯДЫВАНИЯ В БУДУЩЕЕ

1. FVG известна с бара `t` (третьего), вход возможен с `t+1`. Формирующие бары в сделку
   не входят.
2. Свинг известен с бара подтверждения, не с бара пивота.
3. Все условия проверяются на закрытии бара входа; вход по этому же закрытию.
4. Правило разрыва из Phase 0 сохраняется: сигнал отбрасывается, если промежуток до
   предыдущего бара больше одного интервала ТФ.
5. Аудит: будущие бары перезаписываются случайными значениями, набор сигналов обязан не
   измениться. Негативный контроль обязателен.

## 6. ВЕРДИКТ — ТАБЛИЦА ЗАФИКСИРОВАНА ДО ПРОГОНА

Главная величина — **expectancy в R на HELD-OUT**, доверительный интервал bootstrap
(10 000 ресэмплов).

| Вердикт | Условие |
|---|---|
| **A** — сильное подтверждение | `exp >= +0.05R` И нижняя граница CI > 0 И `n >= 100` |
| **B** — умеренное подтверждение | `exp > 0`, но CI включает 0 либо `n < 100` |
| **C** — преимущества не обнаружено | иначе |
| **D** — отрицательный результат | `exp <= −0.05R` И верхняя граница CI < 0 |

Вердикт считает программа. Порог 0.05R взят тот же, что в Phase 0.
