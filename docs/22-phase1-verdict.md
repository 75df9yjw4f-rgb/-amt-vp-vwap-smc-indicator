## Отдельный эксперимент: структурный стоп — РЕЗУЛЬТАТ АРТЕФАКТНЫЙ

На первый взгляд лучший результат всего Phase 1:
`n=363, exp +0.105R, win rate 32.0%, PF 1.15, итог +37.95R, средний R:R 10.68`.

**Это артефакт, а не находка.** Проверка распределения:

| | |
|---|---|
| Медиана R:R | 2.20 |
| p90 / p99 / максимум | 9.26 / 76.76 / **1318.8** |
| Сделок с R:R > 20 | 17 |
| **Их вклад в итог** | **+60.09R из +37.95R, то есть 158%** |
| Минимальный стоп | **0.005 пункта** |
| p10 стопа | 0.75 пункта |
| Типичный спред XAUUSD | 0.20–0.50 пункта |

Когда вход оказывается вплотную к границе FVG, риск стремится к нулю, а R:R — к
бесконечности. Семнадцать таких сделок дают больше, чем весь итог; без них остаток
отрицателен. При этом десятая часть стопов **уже́ внутри спреда** — в реальности они
выбивались бы мгновенно.

Результат сообщается как предупреждение: **без проверки распределения он выглядел бы
открытием.**

## Проверки целостности

| Проверка | Результат |
|---|---|
| Leakage audit (мутация будущих баров) | **40 проверок, 0 утечек** |
| Негативный контроль (чтение бара i+20) | **19 утечек из 30 — тест способен провалиться** |
| FVG подтверждается на 3-м баре, торгуется с 4-го | по построению |
| Свинг известен с бара подтверждения | по построению |
| Вход по закрытию бара сигнала | по построению |
| Правило разрыва из Phase 0 | сохранено |

Негативный контроль пришлось переделывать дважды: первые две версии **не срабатывали**,
то есть аудит ничего не доказывал. Первая утечка (чтение FVG на своём баре) не работала,
потому что зона добавляется в список после проверки входа; вторая (чтение бара i+1)
могла задеть только вход ровно на баре i, а входы слишком редки. Рабочей оказалась
третья — чтение бара i+20.

## Ответ на главный вопрос Phase 1

> **Есть ли у простой механической модели TREND + FVG RETEST положительное expectancy
> на held-out данных?**

**Нет.** Вариант A даёт −0.028R, вариант B — +0.003R, оба CI включают ноль.

По протоколу §8: **останавливаемся, усложнения не добавляем.**

## Что при этом стоит зафиксировать

1. **Направление правильное.** Phase 1 лучше Phase 0 на 0.09–0.12R на сделку. Не значимо,
   но знак устойчив в обоих вариантах. Отказ от торговли против тренда — единственное
   изменение за всё исследование, которое сдвинуло результат в нужную сторону.
2. **Вариант B стоит ровно на нуле** (50.0% при 1:1). Это система без преимущества, но и
   без явного дефекта — в отличие от Phase 0, где дефицит winrate был устойчивым.
3. **Период израсходован.** HELD-OUT просмотрен дважды (Phase 0 и Phase 1). Любая
   следующая гипотеза требует новых данных, иначе это перебор, а не проверка.
4. **Аппарат снова оказался полезнее результата:** он поймал артефакт структурного стопа
   и дважды поймал собственный негативный контроль как неработающий.
