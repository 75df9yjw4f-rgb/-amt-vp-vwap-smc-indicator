# 38 — Проверка премисы самого метода

Метод меряет асимметрию вылазок и на ней строит направление и выходы. Вопрос:
**предсказывает ли эта асимметрия результат на следующем окне?**

Поводом стало наблюдение на четырёх инструментах: наибольшая измеренная
асимметрия (SPX +0.90) дала худший относительный результат, наименьшая
(золото 30m +0.05) — лучший. Корреляция по четырём точкам −0.64.
Четыре точки — ничто, поэтому тест на многих окнах.

## 1. ЗАРЕГИСТРИРОВАНО ДО ПРОГОНА

Окно **3000 баров**, минимум **15 кандидатов** на выводе, минимум **10 сделок**
на тесте — **все пороги объявлены заранее**, как требует урок L1-SPX.
Четыре инструмента, непересекающиеся окна, окно k выводит → окно k+1 проверяет.

**Предсказание: корреляция не выше +0.10.**

## 2. РЕЗУЛЬТАТ — ПРЕДСКАЗАНИЕ ОПРОВЕРГНУТО

**Корреляция +0.388 на 22 парах.** Ни одно окно не отброшено порогами (0 и 0).

| | ожидание следующего окна |
|---|---|
| нижняя половина по асимметрии | **−0.080R** |
| верхняя половина | **+0.145R** |
| разница | **+0.225R** |

Моя догадка про −0.64 оказалась шумом четырёх точек.

## 3. ЧЕТЫРЕ ПРОВЕРКИ, И РЕШАЕТ ПОСЛЕДНЯЯ

**Значимость:** перестановочный p = **0.037**.

**Выбросы:** удаление любой одной пары оставляет корреляцию в
**+0.322 … +0.476** — не выброс.

**По инструментам:**

| | пар | корреляция |
|---|---|---|
| золото 1H | 6 | **+0.791** |
| SPX 1H | 5 | **+0.919** |
| золото 30m | 5 | −0.050 |
| BTC 15m | 6 | **−0.309** |

Работает на 2 из 4, **разворачивается на 2**.

**Leave-one-instrument-out** — порог выводится на трёх, проверяется на четвёртом:

| держим | выше порога | ниже порога |
|---|---|---|
| золото 1H | +0.215R (n=4) | −0.236R (n=2) |
| SPX 1H | +0.475R (n=2) | −0.257R (n=3) |
| золото 30m | **−0.088R** (n=1) | +0.095R (n=4) |
| BTC 15m | **−0.038R** (n=5) | +0.043R (n=1) |

**Два работают, два переворачиваются**, и в ячейках по 1–5 наблюдений.

> **L1-premise: объединённая по инструментам значимость не является
> свидетельством переносимости.** p = 0.037 получено на 22 коррелированных
> парах, посчитанных как независимые. Та же картина уже была на золоте
> в `docs/27`: пул значим, LOSO разворачивается.

## 4. САМЫЙ ШИРОКИЙ ЗАМЕР МЕТОДА ЗА ПРОЕКТ

Четыре инструмента, скользящие окна, **всё вне выборки вывода**:

| | |
|---|---|
| Сделок | **488** |
| Побед | 226 (46.3%) |
| Итог | +13.6R |
| Ожидание | **+0.0279R** |
| 95% CI | **[−0.0745, +0.1304]** |
| Со спредом ~0.02R | **+0.0079R** |
| Победа / убыток | +1.155R / −0.945R |
| Безубыток / факт | 45.0% / 46.3%, запас 1.3 п.п. |

**Метод не отрицателен и не положителен.** После издержек — практически ровно
ноль, CI накрывает ноль с обеих сторон.

## 5. ЧТО ИЗМЕНИЛОСЬ В ПОВЕДЕНИИ

LOSO вносится в **предрегистрацию** каждого теста, где данные объединяются по
инструментам. Объединённый p-value без LOSO больше не приводится как довод.

Это уже второй раз, когда инструмент, введённый после прошлой ошибки, ловит
следующую: контроль со случайными входами поймал фильтр на SPX, а LOSO поймал
пуловую значимость здесь.
