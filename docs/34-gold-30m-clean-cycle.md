# 34 — Эксперимент 4: золото 30m, полностью чистый цикл

**Впервые за проект и вывод гипотезы, и проверка идут на барах, которых я не
видел.** Файл покрывает 2025-01-01 → 2026-09-17; хвост с 2025-11-02 — период,
который я разбирал на 15m, — **отрезан целиком**.

| | Баров | Период | SHA |
|---|---|---|---|
| D-TRAIN | 3 961 | 2025-01-01 → 2025-05-05 | `20b6a24a686271d1` |
| D-TEST | 5 942 | 2025-05-05 → 2025-10-31 | `99901e7be7965dc9` |

Издержки: медианный размах 8.61 при цене ~4038, стоп 2 медианы = 17.2 пункта,
спред 0.30 = **0.017R** — вычтен из всех итогов.

## 1. ЧТО ПОКАЗАЛ D-TRAIN

Дрейф **+24.2%**, база 58.7%.

| Состояние | n | эффект |
|---|---|---|
| `net20 >= +4` | 579 | **+8.3 п.п.** |
| `pos60 > 0.85` | 1 011 | **+8.0 п.п.** |
| `net20 <= -4` | 264 | **−0.0 п.п.** |
| Автокорреляция **размаха**, lag 1 | — | **+0.625** |
| P99/медиана | — | **5.05** |

Два сильнейших состояния — **продолжение** движения, противоположно тому, что
дал биткоин. И оба совпадают с направлением дрейфа.

**Что выдало подлог:** `net20 >= +4` даёт +8.3, а зеркальное `net20 <= -4` —
ровно **−0.0**. Симметричный механизм так себя не ведёт. Односторонний эффект,
совпадающий с дрейфом, — подпись тренда.

## 2. ТРИ ПРЕДСКАЗАНИЯ, ЗАПИСАННЫЕ ДО ОТКРЫТИЯ D-TEST

| | Утверждение |
|---|---|
| **H-A** продолжение (из D-TRAIN) | эффект ≥ **+4.0** п.п. |
| **H-B** возврат (из **биткоина**) | эффект ≤ **−3.0** п.п. |
| **Моё** по закону затухания | **\|эффект\| < 3.0** п.п. |

Закон затухания был выведен из девяти наблюдений: эффект на следующем отрезке ≈
треть от измеренного (золото −9.8 → −5.1 → −0.9; BTC +6.8 → +3.0 → +1.7;
золото NY +3.6 → +0.4). +8.3 → предсказано около +2.8.

## 3. РЕЗУЛЬТАТ

База 57.4%, дрейф **+22.8%** — **знак тот же**, что у D-TRAIN.

| Измерение | D-TRAIN | D-TEST |
|---|---|---|
| `net20 >= +4` | +8.3 п.п. | **−3.1 п.п.** |
| `net20 <= -4` | −0.0 п.п. | **+7.0 п.п.** |
| `pos60 > 0.85` | +8.0 п.п. | −0.1 п.п. |

- **H-A не подтверждена.**
- **H-B подтверждена** (−3.1 против требуемых −3.0).
- **Моё предсказание опровергнуто.**

**Эффект не затух — он перевернулся.** И перевернулся при **неизменном
направлении дрейфа**, поэтому списать это на смену тренда нельзя.

Вдобавок зеркальная сторона выросла с −0.0 до +7.0: на D-TEST картина стала
**симметричным возвратом** — тем самым, что был найден на биткоине.

## 4. ДВЕ ВЕЩИ, КОТОРЫЕ ЭТО МЕНЯЕТ

**Первая. Закон затухания отвергнут как инструмент.**
Он давал ложную уверенность в **знаке**. Правильный априор для любой находки —
не «треть от измеренного», а **«около нуля с неизвестным знаком»**.

**Вторая. Первый перенос между инструментами за весь проект.**
Гипотеза возврата, выведенная на **биткоине** и зарегистрированная до открытия,
подтвердилась на **невиданном золоте 30m**. На самом краю порога и только по
одной из двух сторон — но заранее и на чужом инструменте.

И вот что их связывает: на биткоине эффект был **симметричным** (+9.2 вниз /
−4.3 вверх), и именно он перенёсся. Односторонний `net20 >= +4` с D-TRAIN —
не перенёсся, а перевернулся.

> **BEHAVIOR CHANGE:** симметрия эффекта становится **обязательным** условием
> для выдвижения гипотезы. Односторонний эффект отвергается **без теста**.

## 5. ТОРГОВЫЙ РЕЗУЛЬТАТ — ЧЕСТНО

`REVERSION-CAP-1` точно по спецификации, зафиксированной до открытия:

| | D-TEST (невиданный) | D-TRAIN |
|---|---|---|
| Сделок | 117 | 77 |
| Побед | 55.6% | 54.5% |
| Итог | **+10.3R** | −2.5R |
| Ожидание | +0.088R | −0.032R |
| Со спредом | **+0.071R** | −0.049R |
| p | **0.267** | 0.494 |
| Худшая | −2.50R | −2.50R |

**+10.3R на невиданных данных — но это не край:**

- p = 0.267, от нуля не отличить;
- **LONG +0.232R против SHORT −0.003R** при дрейфе +22.8% — плюс несёт покупка

- та же спецификация на D-TRAIN дала **−0.032R** при том же направлении дрейфа,
  то есть результат непоследователен даже между двумя половинами одного файла.
